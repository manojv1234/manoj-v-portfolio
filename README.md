# Manoj V — Portfolio Website

A responsive, single-page portfolio website created from the supplied resume and profile photo.

## Preview locally
Open `index.html` in any modern browser.

## Publish with GitHub Pages
1. Create a public GitHub repository (for example, `manoj-v-portfolio`).
2. Upload `index.html` and the complete `assets` folder.
3. Open repository **Settings → Pages**.
4. Select **Deploy from a branch**, choose `main` and `/ (root)`, then save.
5. Your website will be published at the GitHub Pages URL shown there.

## Customize
Edit the text in `index.html`. Keep the profile image in `assets/` with the same filename referenced in the HTML.
